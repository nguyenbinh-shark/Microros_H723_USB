# Nhận diện của Trần Nguyên Bình

Các file được sao chép nguyên bản từ `P:\web\website-source\images\logo\`
theo chỉ định của chủ dự án:

- `shark-logo.png`: `favicon-192x192.png`, logo cá mập trắng nền trong suốt.
- `shark.ico`: `favicon.ico`, biểu tượng cửa sổ và shortcut Windows.

Thông tin tên, website, GitHub và email trong `../branding.py` lấy từ
`_config.yml` và `_data/authors.yml` của website cùng ngày chỉnh giao diện.
App dùng bản tài nguyên đã đóng gói trong thư mục này; không cần truy cập
website hoặc ổ `P:\web` khi chạy.
