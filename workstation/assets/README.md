# Icon RPBot Studio

- `rpbot-studio.ico`: icon cửa sổ, taskbar, EXE và shortcut (16–256 px).
- `rpbot-studio.png`: dấu 40 px ở thanh đầu và trang Giới thiệu.

Hình robot nhìn từ trên với vòng quét LiDAR, màu đen/xanh của `studio_theme.py`.
Cả hai file được vẽ bằng `tools/make_app_icons.py` (cần Pillow); sửa hình trong
script đó rồi chạy lại, không sửa tay file ảnh. Icon DAPLink Flasher nằm ở
`tools/assets/`.
